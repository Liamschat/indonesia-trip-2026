备份、发布与离线使用

借电脑时，打开网站 → 编辑模式 → 导入手机备份 → 导出发布文件 → GitHub 上传替换 data/published.json。提交后朋友检查线上更新。公开仓库请勿上传护照、电话或付款凭证。
